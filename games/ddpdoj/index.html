What is real here, and what is not. The ship flies. Its position, velocity, tilt, clamps, speed modes and its two option pods are computed live, by the port, one logic frame per 16.896 ms, from the board's own arithmetic — 0 divergent frames against the board over 2,200 logic frames on 34 compared columns. The picture is pixel-exact: the renderer is the port's own JavaScript and it is identical to MAME on 15,955,968 of 15,955,968 pixels over 159 frames. Everything else you see is a replayed board capture. The port does not build the display list yet (main-loop call #4 $23D2AE is unported, and so are 18 of the 20 object handlers), so the background, the enemies and the HUD are 161 captured frames on a loop — the enemies are not simulated and cannot be hit. There are no weapons and there is no sound. Wave 5 came back BLOCKED: no enemy, shot or bomb handler is translated. Pressing fire drives the ported cadence machine and then reaches a named throw carrying its ROM address, which this page prints rather than freezing on.

How much of this is measured, and by what

Every number on this page came out of a command recorded in docs/worklog/ddpdoj/, run against the real board image under MAME 0.288.

  • The ship: pgm.py flyaround — 0 divergent frames, 34 compared columns, 2,200 logic frames (wave 4).
  • The renderer: pgm.py pixslice — 13,647,872/13,647,872 pixels over 136 frame pairs, with nine deliberate mutations all going red (wave 6). Two of those nine stayed green on the previous corpus, which is how the project found out that palette timing and sprite priority had never been tested at all.
  • The whole demo path: pgm.py demogate — 15,955,968/15,955,968 pixels over 159 frames, port-driven ship included.
  • This page's asset bundle: node games/ddpdoj/tools/bundlegate.mjs — the same 15,955,968/15,955,968, rendered from the 363 KiB published bundle rather than from 58 MiB of cartridge, with four deliberate breaks that all go red.

What is not measured, said plainly: the enemies you can see are a recording, sound is not implemented at all, and no part of this page had ever been run in a browser before it was first published — every check above is headless.
