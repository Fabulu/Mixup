 1. LAUNCH CLAUDE CODE AGAINST GLM / Z.AI              [PS]
-------------------------------------------------------------------------------

  cd C:\programmieren\GLMInst

  Test the endpoint first, launches nothing. Want HTTP 200.

  .\glm-temp.ps1 -Check -Key sk-your-key-here

  Launch:

  .\glm-temp.ps1 -Key sk-your-key-here

  Extra args pass through to claude:

  .\glm-temp.ps1 -Key sk-your-key-here --resume

  Save the key once, then no -Key needed ever again:

  'sk-your-key-here' | Set-Content C:\programmieren\GLMInst\glm.key -Encoding ascii
  .\glm-temp.ps1

  Sets env vars in THAT WINDOW ONLY. settings.json untouched, other Claude
  Code windows unaffected, nothing to undo. Close the window and it is gone.

  -Check results:  200 = working.  401 = key wrong or truncated.
                   403 = account lacks that model, edit the model names at the
                   top of the script.  404 = endpoint moved, not a key problem.

  First message to paste into the new agent: the contents of PROMPT.md

 3. RUN THE GATES (the real verdict - these drive the emulators)
-------------------------------------------------------------------------------

  node tools/test-all.mjs                    Batman   want: 27/27, 0 SKIPPED
  node games/gradius/tools/test-all.mjs      Gradius  want: GREEN, 9 stages, 0 SKIPPED
  python games/ddpdoj/tools/oracle/pgm.py check      DaiOuJou

  A SKIP IS NOT A PASS. Read the skip count. "ALL GREEN" with skips is a red
  run wearing a green hat.

  These are slow - they boot real emulators and run thousands of frames.

-------------------------------------------------------------------------------

 8. COMMIT SAFELY (matters when agents are running)                    [BASH]
-------------------------------------------------------------------------------

  export GIT_INDEX_FILE=.git/mine.index    # BEFORE read-tree, not after
  git read-tree HEAD                       # IMMEDIATELY before committing
  git add path/one.js path/two.js          # BY NAME. never git add -A
  git diff --cached --name-only            # READ THIS before you commit
  git commit -m "..."
  unset GIT_INDEX_FILE
  git push origin HEAD:main

  If git status claims a file is deleted or untracked and you know it is on
  disk, the shared index is poisoned. This clears it, worktree untouched:

  git reset

  NEVER:  git add -A
          git checkout -- <file>        destroys uncommitted work
          force-push, or rewrite history


-------------------------------------------------------------------------------
 9. THE BACKUP                                                        [BASH]
-------------------------------------------------------------------------------

  Refresh C:\programmieren\mixbackup from the current tree:

  rm -rf /c/programmieren/mixbackup
  MSYS2_ARG_CONV_EXCL='*' robocopy "C:\programmieren\batman" "C:\programmieren\mixbackup" /E /MT:16 /R:1 /W:1 /NFL /NDL /NJH /NP

  robocopy exit 1 MEANS SUCCESS. Exit 16 means Git Bash rewrote the /E and
  /MT flags into paths - that is what MSYS2_ARG_CONV_EXCL prevents.

  Clean source in the backup, keeping the 1.5 GB of generated data:

  cd /c/programmieren/mixbackup && git reset --hard
